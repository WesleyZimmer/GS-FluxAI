# Registro de assistência de IA — fluxAI

Este arquivo resume a assistência de IA usada no trabalho de SOA&W. É um registro representativo, não uma transcrição completa de conversas.

## Uso registrado

- **Planejamento:** pedido para revisar o contexto e executar o projeto por etapas, mantendo a matéria de SOA&W como foco.
- **Implementação das etapas anteriores:** apoio na preparação da API ASP.NET Core, persistência SQLite, migrations, configurações versionadas e importação idempotente de uma execução concluída.
- **Fechamento da Etapa 4 (19/11/2026):** pedido para concluir o material local sem publicar no Git naquele momento. A assistência implementou autenticação Bearer local por papel, atualizou a coleção Insomnia sem credenciais, executou a regressão em SQLite temporário, validou o OpenAPI 3.0.3 com Swagger Parser 12.1.0, renomeou o projeto para fluxAI e preparou um ZIP local atualizado. A instalação alternativa do Microsoft.OpenApi.Hidi não avançou porque o feed do NuGet estava inacessível.

## Revisão e responsabilidade

A assistência de IA foi usada para elaborar e modificar código e documentação. Os comandos e respostas registrados devem corresponder ao que foi executado no ambiente local. Os nomes/RMs informados estão no README; a equipe continua responsável pela revisão final e pela aceitação do material antes da submissão acadêmica.
